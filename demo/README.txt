CONTROLS:
WASD - Move
E - Interact (with like everything)
G - Gift
P - Plant Seed
T - Open Inventory
V - Open Quests
Space - Use Tool
Cycle Tool - Q
Cycle Seeds - R
H - Open Help

And like -, +, and others for the camera

More info -> Run anyway
